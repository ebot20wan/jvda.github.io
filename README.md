# Jay Vincent D. Antonio — JAY.AI Portfolio

A custom-coded, responsive portfolio for AI training, data annotation, and AI output quality review. Built with plain HTML, CSS, and JavaScript; no build step, framework, database, or paid service is required.

## Files

- `index.html` — all page content, sections, metadata, and demo markup
- `styles.css` — responsive dark-blue visual system
- `script.js` — mobile navigation, certified-skill search, and interactive demo logic
- `assets/jay-antonio.jpeg` — profile photograph supplied by Jay
- `assets/Jay_Vincent_D_Antonio_Resume.pdf` — resume PDF
- `assets/favicon.svg` — browser tab icon

## Publish with GitHub Pages

1. Open the repository `https://github.com/ebot20wan/ebot20wan.github.io`.
2. Upload the contents of this folder to the repository root (not the enclosing folder). Keep the `assets` folder and its contents.
3. When prompted, commit the changes to the `main` branch.
4. In repository Settings → Pages, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for the Pages deployment to finish, then visit `https://ebot20wan.github.io`.
6. If the browser shows an older version, hard-refresh with `Ctrl + Shift + R`.

## Updating content

- Edit text and sections in `index.html`.
- Edit appearance in `styles.css`.
- Edit interactive behavior in `script.js`.
- Replace the profile photo only if you keep the filename `jay-antonio.jpeg` (or update the `src` in `index.html`).
- Replace the resume only if you keep the filename `Jay_Vincent_D_Antonio_Resume.pdf` (or update both resume links in `index.html`).

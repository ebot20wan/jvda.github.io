# Jay Vincent D. Antonio — Portfolio Website

Responsive static portfolio for AI Trainer / Data Annotator opportunities.

## Preview locally
Open `index.html` in a modern browser. Keep the `assets` folder beside it.

## Publish free with GitHub Pages (beginner steps)
1. Create a free account at https://github.com/ if you do not already have one.
2. Sign in and click **New repository**. Name it `YOUR-USERNAME.github.io` (replace with your actual GitHub username).
3. Set repository visibility to **Public**, then create the repository.
4. On the new repository page, choose **Add file → Upload files**.
5. Extract this ZIP on your computer. Upload the contents of the `jay-antonio-portfolio` folder, including `index.html`, `styles.css`, `script.js`, and the `assets` folder. Do not upload only the ZIP file.
6. Commit the uploaded files to the `main` branch.
7. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
8. Wait a few minutes. Your site should appear at `https://YOUR-USERNAME.github.io/`.

Official guide: https://docs.github.com/en/pages/quickstart

## Important before publishing
- Confirm your email address, phone number, location, and resume are current and that you want them public.
- This repository is public, so the website source files will also be visible.
- GitHub Pages hosting is free for public repositories, but subject to GitHub's terms and usage limits. Keep this ZIP as your backup.
- A custom domain is optional and normally costs money; the free `github.io` address is enough for job applications.
- Do not upload client-confidential annotation data, private task screenshots, or personal information belonging to others.
- Replace or expand workflow summaries only with accurate, approved, non-confidential examples.
